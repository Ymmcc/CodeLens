# CodeLens · 本地代码解释浮窗

CodeLens 是一个 Windows 托盘工具，用本机 Ollama 解释选中的代码并回答追问。

## 构建与启动

准备 Windows x64、.NET Framework 4.8 和 Ollama。首次使用前请确认 Ollama 已有 `qwen3.5:9b` 模型，缺少时可用 `ollama pull qwen3.5:9b` 下载。

在仓库根目录运行 `.\build.ps1`。脚本使用 Windows 自带的 .NET Framework C# 编译器，在同目录生成 `CodeLens.exe`。双击它，工具会驻留在系统托盘。

## 使用方法

1. 在浏览器或编辑器里选中一段代码。
2. 按 **Ctrl+Alt+Q**。浮窗以能容纳简短解释的高度打开，并显示选区读取状态。内容超过可用空间时，窗口会平滑增高，到达高度上限后可在窗口内滚动。点击标题栏的「原文」可预览这次选中的内容。
3. 从标题栏拖动浮窗。切回浏览器或编辑器时，浮窗会保留当前内容。
4. 解释完成后，在底部输入问题，按 **Enter** 或点击 **发送**。短选区最多追问 4 次，中等选区 3 次，长选区 2 次，接近上下文上限的选区 1 次。追问只围绕你问到的内容。遇到无法从片段确认的部分，模型会提示需要补看哪段定义。模型参考最近一轮追问，浮窗会保留完整的可见对话。
5. 按 **Esc** 或点击关闭按钮收起。选中新代码并按快捷键会开启一次新的解释。右键托盘图标可退出工具。

工具通过 Windows 辅助功能接口读取当前前台窗口明确选中的文本，最多读取 7,000 个字符。应用需要提供可读取的文本选区。选区位置不可用时，浮窗会显示在鼠标附近。

选区和当前追问上下文只发给 `127.0.0.1:11434` 上的 Ollama，使用已安装的 `qwen3.5:9b`。工具不操作剪贴板。对话只保留在当前浮窗中。Ollama 未运行时，首次分析会尝试在后台启动它。Ollama 服务可以在退出浮窗工具后继续运行。
